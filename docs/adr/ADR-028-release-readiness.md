# ADR-028 — Release readiness: what Phase 7 did in the repository and what it could not

**Status:** Accepted (Phase 7 build, 15 Nov 2026).

## Context

Phase 7 is "localization and accessibility pass, QA, pilot, release" (E12, E13). Part of that is code and tests. Most of it needs a phone, merchants, reviewers or a store account, none of which exist inside a repository. This ADR draws the line so that "Phase 7 done" is never read as "ready to ship".

## Decisions

### Accessibility (SK-1203)

1. **Every screen is checked by test, in light and dark themes,** against three of Flutter's accessibility guidelines: touch targets of at least 48dp, a label on everything that can be tapped, and WCAG text contrast. The checks sit beside the existing large-text test (English and Telugu, 2x text, 320dp wide), so a new screen added to that list gets all of them.
2. **The checks were confirmed to bite**: a deliberately unlabeled button and low-contrast text fail them.
3. **Not covered by test:** TalkBack reading order, focus order with a keyboard, and colour-blind review of the balance colours (the app already never uses colour alone: every balance has its direction in words). These are on the device checklist.

### Localization (SK-1201, SK-1202)

4. **A test fails the build if a screen holds hard-coded text.** It looks for string literals with letters passed to text, labels, titles, tooltips and hints in presentation code. The only allowed literal is the debug-only gallery link.
5. **English and Telugu must define the same messages with the same placeholders**, and every Telugu message must contain Telugu script (existing test).
6. **Telugu is still a draft.** Nothing in this phase changes that; only native-speaking shop owners can (SK-0005).
7. **Dates and times** follow the selected language through `intl`. Numbers stay in Indian digit grouping with Western digits in both languages. *Review with merchants:* do Telugu users expect Telugu digits anywhere?

### QA

8. **A cost test** seeds 400 parties and 12,000 ledger entries and requires every report, list and reminder query to finish well inside two seconds on a development machine. It guards against a query turning quadratic; it is not the PRD's performance measurement, which needs the reference phone.
9. **A device smoke test** (`integration_test/app_smoke_test.dart`) walks first-run setup to Home on a real device. **It has never been run**, because no device or emulator was available. Its header says so.
10. **A device checklist** (`docs/release/device-test-checklist.md`) lists everything that only Android can prove: plugins, permissions, the share sheet, the file picker, the Keystore, notifications, the restart after a restore, kill-during-write, Telugu rendering, and timing.

### Release

11. **App icon:** an adaptive icon (vector ledger on the brand green) for Android 8 and later, PNGs of the same drawing for Android 7.x generated by `tool/generate_launcher_icons.py`, and a one-colour notification icon kept from the resource shrinker by `res/raw/keep.xml`. iOS icons are untouched; iOS is not a V1 target.
12. **Store and privacy texts are drafts for counsel**, written from what the code does: `docs/release/play-data-safety-draft.md` and `docs/release/privacy-notice-draft.md`. They carry no publisher name or contact because none has been decided.
13. **`docs/release/release-checklist.md` is the single list of what remains**, as five gates: run on a phone; four outside reviews; owner decisions; pilot; Play Store.
14. **No version bump and no tag.** The version stays `1.0.0+1`. Tagging `v1.0.0` is the owner's act, after the gates.

### What Phase 7 does not claim

15. The app has **not been run on any device**.
16. The **backup encryption has not been reviewed** (ADR-026).
17. **No merchant has used it**; there has been no pilot.
18. **No accountant, Telugu speaker or lawyer has reviewed** their part.
19. **PDF statements are not built** (ADR-025).

## Consequences

- The automated suite is the only evidence of correctness so far. It is broad (financial rules, rollback, idempotency, every screen in two languages and two themes, backup tampering, restore across database files), but it runs on a desktop SQLite and fake plugins.
- The first hours on a real phone will find things. That is expected and is Gate 1, not a regression.
